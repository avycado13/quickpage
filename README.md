# QuickPage

This is a homepage for your browser that shows essential info for your school day.

## Demo Video
[Demo](https://www.youtube.com/watch?v=9AI308Zf9JI)

## Features
- Google classroom card
- Calendar Card
- Google tasks card
- Notepad Card
- Weather
- Drag and drop layout
- Gmail Card
